# Hedge Funds
**Nova SBE · Prof. Carlos Duarte D'Almeida · 2024/25**

---

This directory contains four assignments completed for the Hedge Funds course. The projects progress from classical systematic strategy design, through macro derivatives trading, cross-sectional factor investing, and statistical arbitrage — covering both the theoretical foundations and full quantitative implementation of each approach.

| # | Project | Language | Topic |
|---|---|---|---|
| 01 | Portfolio Backtesting | Python | Trend-following and mean-reversion across equities, bonds, and commodities |
| 02 | Macro Trade Analysis | Python | FX derivatives pricing anomalies (USD/KRW, USD/CHF) |
| 03 | Factor Investing | Python | Long/short equity factor model on the S&P 500 universe |
| 04 | Statistical Arbitrage | Python | Pairs trading portfolio with cointegration screening |
